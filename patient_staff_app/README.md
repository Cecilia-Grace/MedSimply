PatientStaffApp

PatientStaffApp is a Django REST Framework application designed to manage patients and their assignments to health workers.

Admins can manage all patients, while health workers can access only their assigned patients.

Includes a Login History model to track user logins for auditing and security purposes.

Provides secure API endpoints with role-based access control.

Future improvements: adding notifications for patient updates, reporting dashboards, and enhanced analytics for health worker performance.
